# Интерфейс

- Слои и направление импортов: `app → pages → features → shared`.
- Импорты только через алиас `@/`.
- Запросы к API — только через `shared/api` (`api`, хуки). Компоненты не
  вызывают `fetch` напрямую.
- Интерфейс не считает остатки сам: показывает числа, которые прислал
  бэкенд. Единственный источник правды об учёте — сервер.
- Ошибки ветвятся по `ApiError.code`, а не по тексту сообщения.
- Создающие операции отправляются с `Idempotency-Key`.
- Коды бэкенда переводятся в слова в `shared/lib/labels.ts`.
