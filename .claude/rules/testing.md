# Тесты

- Стиль сценариев: класс `When…`, метод `it_…`. Название читается как
  утверждение о поведении.
- `tests/domain` — чистый Python, без базы и фикстур.
- `tests/e2e` — через HTTP на настоящей PostgreSQL. Базу не подменяем:
  блокировки, CHECK-ограничения и транзакции — часть проверяемого поведения.
- Действия выполняются через `tests/e2e/harness.py`. Каждое изменяющее
  действие там сразу запускает сверку журнала с остатками — не обходите его
  прямыми запросами к клиенту.
- Новая операция учёта — это минимум три теста: обычный путь, нехватка,
  повторное подтверждение.
- Для гонок используйте `asyncio.gather` с реальными параллельными запросами.
